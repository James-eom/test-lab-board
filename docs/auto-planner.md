## 배치와 확정

탐색은 최대 100,000회 또는 약 3초로 제한한다. 가능한 일정 중 전역 최적 배치를 보장하지 않는다. 모든 시험을 배치하지 못하면 각 미배치 항목과 원인을 표시하며 일괄 확정을 막는다. 탐색 한도에 도달한 경우에는 배치 불가능이라고 단정하지 않는다. 미래 연도의 일반 시험은 공휴일 자료가 확인되어야 배치한다. API가 실패하면 이미 확인된 자료를 사용할 수 있다.

미리보기는 DB에 예약을 저장하지 않는다. 서버 메모리에 사용자별 30분 유효 일정안을 보관하며, 서버 재시작 시 다시 생성해야 한다. 브라우저는 일정안 ID만 보내 확정한다. 확정 시 예약·운영 기준·공휴일·설비 정지·사용자 정보를 다시 비교하고, 바뀌었다면 새 일정안을 요구한다.
